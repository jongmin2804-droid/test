## 이론

### AI로 코드 만들기

생성형 AI는 사람의 말로 쓴 요구사항을 읽고 프로그램 코드를 만들어 낸다. 만들려는 기능을 정확하게 설명할 수 있으면 문법을 모두 외우지 않아도 동작하는 코드를 얻을 수 있다.

AI를 이용한 코딩은 [[표 3-1]]과 같이 다섯 단계로 진행한다.

[표 3-1] AI를 이용한 코딩의 다섯 단계 {first-col widths=18,44,37}
| 단계 | 하는 일 | 확인할 점 |
|---|---|---|
| 요구사항 | 만들 기능을 요구사항 카드에 정리한다. | 핀 번호, 동작 규칙, 확인 방법이 모두 들어 있는가 |
| 계획 | 코드를 쓰기 전에 구현 계획을 설명하게 한다. | 계획이 의도한 동작과 같은가 |
| 코드 | AI가 코드를 생성한다. | 핀 번호와 코드 구조가 요구사항에 맞는가 |
| 업로드 | Arduino IDE에서 컴파일하고 보드에 올린다. | 컴파일 오류가 없는가 |
| 확인 | 실제 동작을 측정하고 기록한다. | 측정 결과가 기준을 만족하는가 |

### delay()와 millis()

`delay()`는 지정한 시간 동안 프로그램 전체를 멈춘다. `millis()`는 프로그램이 시작된 뒤 흐른 시간을 ms 단위로 알려 주므로, 프로그램을 멈추지 않고도 일정한 주기로 점멸시킬 수 있다.

## 실습

### 회로 구성

황색 LED 2개를 [[표 3-3]]과 같이 배선한다. 핀 번호는 [[부록 A]]의 표준 핀맵을 따른다.

[표 3-3] 방향지시등 배선 {widths=63,37}
| 부품 | 연결 |
|---|:---:|
| 왼쪽 방향지시등(황색 LED + 330Ω 저항) | D7 |
| 오른쪽 방향지시등(황색 LED + 330Ω 저항) | D8 |
| 각 LED의 짧은 다리(−) | GND |

### 코드 생성과 검토

생성된 코드는 보드에 올리기 전에 다음을 확인한다.

1. 핀 번호가 표준 핀맵과 같다.
2. 핀 번호가 `const int LEFT_LAMP = 7;` 과 같이 상수로 선언되어 있다.
3. 점멸 시간을 `millis()`로 처리한다.

### 점멸 주기 측정

스톱워치로 10초 동안의 점멸 횟수를 세 번 세어 평균을 구하고, 6을 곱해 1분당 횟수로 환산한다.

## 예시 코드

```cpp C1.ino | C-1 방향지시등·비상등
// C-1 방향지시등·비상등 (3장)
const int LEFT_LAMP  = 7;    // 왼쪽 방향지시등
const int RIGHT_LAMP = 8;    // 오른쪽 방향지시등
const unsigned long BLINK_MS = 400;  // 켜짐 400ms + 꺼짐 400ms → 1분에 75회

bool leftOn  = true;   // 왼쪽 깜빡이 켬 (비상등: 둘 다 true)
bool rightOn = false;
bool blinkOn = false;
unsigned long lastToggle = 0;

void setup() {
  pinMode(LEFT_LAMP, OUTPUT);
  pinMode(RIGHT_LAMP, OUTPUT);
}

void loop() {
  if (millis() - lastToggle >= BLINK_MS) {  // 400ms가 지났으면
    lastToggle = millis();
    blinkOn = !blinkOn;                     // 켜짐 ↔ 꺼짐
  }
  digitalWrite(LEFT_LAMP,  leftOn  && blinkOn);
  digitalWrite(RIGHT_LAMP, rightOn && blinkOn);
}
```
